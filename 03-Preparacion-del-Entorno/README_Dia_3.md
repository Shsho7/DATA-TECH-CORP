# Día 3 – Preparación del entorno

## Objetivo
Preparar el entorno de desarrollo, crear una aplicación Flask inicial y configurar la base de datos SQLite.

## Archivos
- `app.py`: aplicación web inicial.
- `database.py`: creación de las tablas Usuarios y Solicitudes.
- `requirements.txt`: dependencia necesaria para ejecutar Flask.
- `Preparacion_del_Entorno.docx`: explicación de las herramientas.
- `Diseno_Inicial_de_la_Base_de_Datos.docx`: descripción de las tablas.
- `Registro_de_Horas_Dia_3.docx`: planificación estimada y espacio para horas reales.

## Pasos para probar en una computadora
1. Instalar Python si todavía no está instalado.
2. Abrir una terminal dentro de esta carpeta.
3. Crear un entorno virtual con `python -m venv .venv`.
4. Activarlo en Windows con `.venv\\Scripts\\activate`.
5. Instalar Flask con `pip install -r requirements.txt`.
6. Ejecutar `python app.py` (o `py app.py` en Windows).
7. Abrir `http://127.0.0.1:5000` en el navegador. Debe aparecer el mensaje de la aplicación inicial.

La base de datos `data_tech_corp.db` se crea automáticamente al iniciar la aplicación.
